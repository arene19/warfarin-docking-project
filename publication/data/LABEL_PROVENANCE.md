# Label provenance and mapping assumptions

## Training corpus

Primary file: `data/coagulation_admet_multi_task.csv` (18,966 compounds).

| Source | Endpoints | Notes |
|--------|-----------|-------|
| ChEMBL bioactivity | All six tasks | IC50 and Ki records pooled; duplicate measurements mean-aggregated per `(canonical_smiles, target)` |
| Active-learning merges | VKORC1 only | `RL_Gen_*` flexible Vina affinities converted via pseudo–pXC50 = −ΔG / 1.36 (train partition only after hold-out guard) |

See `publication/data/gnn_vkorc1_label_audit.json` (generated by `gnn_baseline_evaluation.py`) for train/test counts. The train set includes **26** VKORC1 labels whose canonical SMILES overlap the RL screening library (SMILES overlap, not label provenance); the held-out test set includes 41 VKORC1 labels with **23** classified as ChEMBL-only and **18** as RL-library SMILES overlaps under the expanded SMILES resolution (config + SDF). Supplementary metrics excluding RL-library SMILES from test are in `publication/data/gnn_vkorc1_chembl_only_benchmark.json` (Table S5).

## Assay harmonization

- **IC50 vs Ki:** Not distinguished in the master table; both mapped to pXC50 = −log10(value_nM × 10⁻⁹).
- **Vina pseudo-labels:** AutoDock Vina best-mode ΔG (kcal/mol) mapped with fixed slope 1.36 kcal/mol per log unit. This is an approximate weak-supervision step for the active-learning loop, not experimental potency.

## Benchmark vs case study

- **§3.1 GNN benchmarks:** Murcko scaffold hold-out on the full master table (ChEMBL + RL pseudo-labels where present). Table S5 reports VKORC1 metrics with RL pseudo-labels excluded from test.
- **§3.3 RL case study:** Flexible docking ranks **within the `RL_Gen_*` library only**; reference ligands are not comparative benchmarks in the manuscript.

## Active-learning guard

`active_learning_merger.py` skips val/test SMILES listed in `publication/data/gnn_scaffold_split.json` so new RL pseudo-labels do not overwrite held-out benchmark partitions.
